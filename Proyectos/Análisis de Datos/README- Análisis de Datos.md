# 💼 Caso Real

## 🏋️ FORZA — Diagnóstico Operacional (2025)

Análisis integral sobre datos operativos de un centro de entrenamiento utilizando información real extraída desde CROSSFY.

El proyecto incluyó:
- análisis de ocupación,
- retención de socios,
- uso de paquetes,
- comportamiento de asistencia,
- y detección de ineficiencias operativas.

### 📌 Hallazgos principales

- 27.8% de los turnos comprados vencen sin utilizarse
- Solo el 24% de la cohorte inicial continúa activa después de 20 meses
- La ocupación promedio es del 47%, mostrando capacidad ociosa
- Un único producto representa el 51% del total de ventas

# 🧪 Exploración Técnica

## 🏎️ Fórmula 1 Historical Analysis (1950–2024)

Proyecto exploratorio desarrollado en Power BI utilizando más de 70 años de datos históricos de Fórmula 1.

El análisis explora:
- rendimiento de pilotos y escuderías,
- impacto de la pole position,
- evolución de abandonos,
- y tendencias históricas de pit stops.
