# 🔬 Ciencia de Datos

Proyectos orientados a análisis estadístico, modelado predictivo y exploración de patrones utilizando machine learning y datasets públicos.

Los trabajos de esta carpeta incluyen:
- análisis exploratorio,
- validación de hipótesis,
- visualización,
- entrenamiento de modelos,
- y evaluación de resultados.

---

## 📁 Proyectos

### ⛽ Precios de combustibles en Argentina (2016–2024)

Análisis histórico de precios de combustibles en Argentina utilizando datos públicos de estaciones de servicio.

El proyecto explora:
- evolución temporal de precios,
- diferencias regionales,
- comportamiento por tipo de combustible,
- y entrenamiento de modelos predictivos.

### 📌 Análisis realizados

- Tendencia histórica de precios
- Comparación entre provincias y AMBA
- Variabilidad según tipo de combustible
- Distribución regional
- Modelado predictivo con machine learning
